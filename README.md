# Pass — Landing de venta (GitHub Pages)

Página estática para vender licencias de Pass ($15 pago único). Compra vía Discord.

## Publicar en GitHub Pages (gratis)

1. Crea un repo público, por ejemplo `pass-landing`.
2. Sube `index.html`, `icon.png`, `logo.png` y `.nojekyll` a la raíz.
3. En el repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root)** → Save.
4. En ~1 minuto quedará en `https://TUUSUARIO.github.io/pass-landing/`.

## Notas
- El botón de compra apunta a tu Discord. Ideal: cambia ese enlace por una **invitación** (`https://discord.gg/XXXX`) para que el comprador pueda unirse; los enlaces `discord.com/channels/...` solo funcionan si ya está dentro del servidor.
- Sin servidor: es 100% estático.
